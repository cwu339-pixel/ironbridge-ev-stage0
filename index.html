01 Site introduction

项目 / 场地介绍

Marnwood Hall 位于 Buildwas Road 前场位置，项目判断应先从场地属性和场站定位出发，再看车流、竞争和真实使用情况。

场地介绍

Marnwood Hall 位于 Buildwas Road, Ironbridge，处于 Ironbridge / Broseley / Madeley 本地出行圈层的前场位置。 场地面向主路，具备较好的 frontage 可见性，更适合作为本地需求承接点，而不是封闭式目的地站点。

场站介绍

拟建充电场站位于场地前侧，紧邻 Buildwas Road frontage。该点位不是典型 meal-stop 场景，而是一个 frontage-led local charging point， 核心在于承接周边已存在的公共充电需求，并验证其作为本地补能节点的可行性。

区位属性

更接近 town-edge / local-through-traffic / frontage capture 场景，不是隐藏在后场或封闭园区内部的点位。

当前阶段重点

先验证周边真实需求、竞争格局以及场地自身承接能力，而不是直接给投资回报结论。

判断逻辑

这个项目不是复制某个成熟快充站，而是判断它能否承接 Ironbridge 周边已经存在的公共充电需求。

当前更合理的定位是 town-edge / local-through-traffic / frontage capture 场景，而不是封闭式目的地站点或成熟 meal-stop 节点。

06 Risk and next step

风险、关键缺口与下一步动作

当前最稳的表述不是“值得投”，而是“值得继续验证”。这一页把 Stage-0 还没有证明的东西收口成风险和 next-step gate。

Risk What we know now Why it matters Next-step proof
Capture risk 区域真实活动主要集中在 KFC rapid 与 Tesco retail 节点，Marnwood Hall 自身还没有直接 usage 证明。 新站不一定能复制成熟节点的周转。 补 site visit read-through、host fit、pricing / dwell-time 假设。
Grid and layout 当前只有 frontage 与场景判断，没有正式 grid quote，也没有 charger layout。 连接成本、进出流线和 bay 落位仍可能改变方案。 进入 Stage-1 后先做 desktop grid check 与 preliminary layout。
Window depth 当前窗口约 3.1 天，适合做初筛，不适合做季节性结论。 短窗可能低估或高估周末/工作日结构。 继续刷新监控窗，并在后续版本补 weekday / weekend 读法。
What is already proven

本地 comparable pool 已经证明区域里有真实公共充电活动，且活跃度集中在 KFC rapid 和 Tesco retail 两类节点。

What is not yet proven

Marnwood Hall 本点能拿到多少 capture，还没有被 frontage、pricing、access 和 dwell-time 证据证明。

Recommended gate

进入 Stage-1，但只做小额开发验证：desktop grid check、site visit replay、layout、parking/access 和 host readiness。
